# Contributing

You do not need to write code to help. Most of the work happens outside GitHub: in homes, streets, council meetings and workshops. GitHub is where we coordinate and keep score honestly.

## Ways to take part

- **Do a task.** Find one on the site, comment `/claim` on its issue, and get going.
- **Report what you did.** Use the *Report an action* form, with numbers and a way to check them.
- **Start or join a chapter.** Use the *Start or list a local chapter* form.
- **Propose a task.** Use the *Propose a task or project* form.
- **Fix a number.** Use the *Correct a number or add a source* form. Link an official or peer-reviewed source.
- **Improve the site or scripts.** Open a pull request. Keep it small and explain why.

## Before you post

- Share a city or region, not a home address, phone number or private email.
- Do not post other people's details without their permission.
- Give a source or say how you worked a number out.
- Use peaceful methods only. Proposals that depend on violence, harassment or deception will be closed.

## Pull requests

1. Fork the repository and make a branch.
2. Change what you need. If you touched `scripts/` or the data files, run `node scripts/test.mjs`.
3. Open a pull request and say what it changes and why.

Be patient with reviewers, who are volunteers.
